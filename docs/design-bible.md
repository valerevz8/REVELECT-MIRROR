# REVELECT Design Bible

## Purpose
REVELECT exists to help people see themselves more clearly.

It is not a personality test.
It is a quiet editorial reflection experience.

### Body

## Hero
One reflection.

# See Clearly.

## Rules
- Preserve layout
- Prefer whitespace
- Avoid dashboards
- Avoid gradients
- Remove instead of adding
